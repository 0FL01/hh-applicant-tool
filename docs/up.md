### 1.2 Обход капчи через VLM — Новое в апстриме

В апстриме добавлен `_solve_captcha_async()` в `apply_vacancies.py`:
- Использует Playwright (headless Chromium) для перехода на URL капчи
- Делает скриншот капчи
- Отправляет в **Vision Language Model** (`ai/openai.py::solve_captcha()`) через OpenRouter/OpenAI
- Вставляет распознанный текст, синхронизирует куки обратно в requests-сессию

Это **крупная фича антидетекта** — капчи hh.ru решаются автоматически без участия пользователя. В локале **вообще нет обработки капчи** (просто ловится `CaptchaRequired` и пишется ошибка).

### 1.3 Отдельный прокси для OpenAI/AI трафика — Новое в апстриме

Апстрим `main.py`:
- Флаг `--openai-proxy` / `--ai-proxy`
- Отдельная `openai_session` (`requests.Session`) со своей цепочкой прокси
- Используется для всех AI-вызовов (сопроводительные письма, фильтр вакансий, капча)

В локале один прокси на всё. Это важно для антидетекта — можно пустить трафик к API HH через российский прокси, а AI-трафик через другой.

## 2. AI-ФИЛЬТРАЦИЯ И ПОИСК ВАКАНСИЙ (Новое в апстриме)

### 2.1 AI-фильтр вакансий (`--ai-filter heavy|light`)

В апстриме — **полностью новая система AI-фильтрации**, которой нет в локале:

- **`heavy` режим:** Анализирует полное резюме (заголовок, навыки с описаниями, опыт с компаниями/датами) + полное описание вакансии + key_skills + employment_form. LLM спрашивается "подходит ли?"
- **`light` режим:** Быстрая проверка — заголовок резюме + skill_set против названия вакансии + key_skills
- **Промпты:** зашиты в `apply_vacancies.py` (`_build_filter_system_prompt_heavy/light`)
- **Кеширование анализа резюме:** `_resume_analysis_cache` по ключу `(resume_id, mode)` — не анализировать одно резюме дважды
- **Сохранение пропущенных вакансий:** таблица `skipped_vacancies` — не проверять повторно отклонённые
- **3 retry** с гибким парсингом JSON (`{"suitable": true/false}`)

Штука полезная для массовых откликов, когда нужно предварительно фильтровать вакансии через AI.

### 2.2 AI-фильтр email (`--ai-filter` в связке с email парсингом)

Апстрим улучшил извлечение email в `_parse_site()` и добавил AI-фильтрацию найденных email — отсеивает мусорные/одноразовые адреса.

## 3. НОВЫЕ КОМАНДЫ (Только в апстриме)

### 3.1 `ui.py` — Веб-интерфейс на `pywebview` (20+ файлов)

Масштабная фича: полноценный GUI:
- `ui/api.py` — бэкенд Web API
- `ui/presets.py` — пресеты для откликов
- `ui/templates/index.html` + CSS + JS — нативное окно с HTML
- `start.py` — лаунчер для Windows с автоустановкой и автозапуском
- 5 тестов для UI

Неактуально для серверного/CLI-использования, но добавляет зависимость `pywebview`.

### 3.2 `create_resume.py` — Создание резюме из Markdown-шаблона

Новая команда + `utils/resume_md.py` (534 строки): парсит `.md` шаблон резюме, определяет индустрию/специализацию через API HH и создаёт резюме на hh.ru. `--publish` для автопубликации.

### 3.3 `clear_skipped.py` — Управление пропущенными вакансиями

Очистка таблицы `skipped_vacancies` (вакансии, отсеянные AI или фильтром). `--reason` для фильтрации по причине, `--dry-run`.
